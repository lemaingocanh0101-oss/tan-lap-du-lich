WEBSITE DU LỊCH TÂN LẬP – DẤU ẤN BIÊN CƯƠNG

1. Giải nén tan-lap-du-lich.zip.
2. Mở index.html trong trình duyệt hoặc mở cả thư mục trong VS Code > Live Server.
3. Để công khai miễn phí: tạo repository GitHub mới, tải index.html và thư mục assets lên; vào Settings > Pages > Deploy from a branch > main / (root) > Save.
4. Website thuần HTML/CSS/JavaScript, không cần WordPress hoặc hosting PHP.
5. Để chỉnh thông tin, mở index.html trong VS Code. Các hình ảnh trong assets do bạn cung cấp.
6. Những điểm đến, đơn vị ăn uống/lưu trú và thông điệp được lấy từ bộ slide nhóm 3. Cần xác minh tình trạng hoạt động, vị trí thực tế, quy định tham quan trước khi xuất bản thông tin làm hướng dẫn du lịch chính thức.
7. Website là bản giới thiệu, không chứa hệ thống bán tour hoặc đặt phòng thật.
Cập nhật triển khai website Tân Lập trên Cloudflare Pages.
